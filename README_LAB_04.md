
# Лабораторна робота №4
## Типи, тести, пакування і CLI
### Мета роботи

Закріпити роботу з анотаціями типів Python, статичною перевіркою коду, автоматизованим тестуванням, CLI-інтерфейсами та пакуванням Python-проєктів.

### Опис проєкту

`findex` — консольна пошукова система, яка створює інвертований індекс текстових документів і виконує ранжований пошук за запитами користувача.

У лабораторній роботі додано:
- анотації типів для функцій та структур даних;
- протокол `Scorer` для реалізацій алгоритмів оцінювання;
- перевірку типів за допомогою Pyright у режимі strict;
- автоматизовані тести за допомогою pytest;
- генеративне тестування за допомогою Hypothesis;
- CLI на основі Typer;
- форматований вивід за допомогою Rich;
- пакування проєкту та встановлення через uv;
- автоматичну перевірку коду через GitHub Actions.

### Команди CLI

Створення індексу:

```bash
findex index --data data --output index_v4.bin
```

Пошук:

```bash
findex search "python"
```

Вибір алгоритму TF-IDF:

```bash
findex search "python" --scorer tfidf
```

Виведення результатів у JSON:

```bash
findex search "python" --json
```

Статистика індексу:

```bash
findex stats
```

Режими докладності логування:

```bash
findex -v search "python"
findex -vv search "python"
```

### Тестування

Для тестування використовується pytest.

Покрито тестами:
- токенізацію, зокрема Unicode-текст;
- побудову інвертованого індексу;
- логічні операції та розбір запитів;
- роботу алгоритмів TF-IDF і BM25;
- збереження та завантаження індексу;
- роботу CLI-команд;
- властивості структур даних за допомогою Hypothesis.

Для перевірки покриття використовується pytest-cov.

**Покриття коду:** буде внесено фактичний відсоток після отримання результатів CI.

**Непокритий код:** буде зазначено за результатами звіту pytest-cov, якщо такі ділянки залишаться.

### Інструменти

- Python 3.11+
- uv
- pytest

- pytest-cov
- Pyright
- Ruff
- Typer
- Rich
- Hatchling
- GitHub Actions

### Автоматична перевірка

GitHub Actions автоматично запускає:
1. встановлення залежностей;
2. перевірку стилю коду через Ruff;
3. статичну перевірку типів через Pyright;
4. автоматизовані тести з вимірюванням покриття.

Перевірка запускається після push у гілку `main` та під час створення Pull Request.

### Встановлення як інструмента

```bash
uv tool install .
```

Після встановлення програма доступна через команду:

```bash
findex --help
```

### Висновок

У лабораторній роботі було розширено пошукову систему `findex`: додано CLI, автоматизовані та генеративні тести, анотації типів, статичну перевірку коду й конфігурацію пакування. Також налаштовано GitHub Actions для автоматичного контролю якості проєкту.
