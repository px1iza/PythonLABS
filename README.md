
# Лабораторна робота №2
## Інвертований індекс: словники, хешування та пам'ять

**Проєкт:** findex  
**Мова програмування:** Python 3.13

## 1. Мета роботи

Мета лабораторної роботи — навчитися створювати інвертований індекс за допомогою словників, дослідити особливості хешування та порівняти різні способи зберігання даних за використанням пам'яті.

У роботі реалізовано побудову інвертованого індексу, булевий пошук, збереження індексу у файли різних форматів та вимірювання продуктивності.

## 3. Побудова інвертованого індексу

Інвертований індекс — це структура даних, яка зберігає інформацію про те, у яких документах зустрічається кожне слово.

Для побудови індексу використовується `defaultdict`, який автоматично створює порожні значення для нових ключів.

Для кожного терміна зберігаються:
- ідентифікатор документа;
- кількість входжень терміна в документ.

Також зберігається довжина кожного документа.

Для ефективнішого пошуку списки входжень упорядковуються за ідентифікаторами документів.

## 4. Моделі даних

У проєкті використовуються класи `Posting`, `DocMeta` та `InvertedIndex`.

Класи `Posting` і `DocMeta` оголошені з параметрами `frozen=True` та `slots=True`.

`frozen=True` забороняє змінювати поля об'єкта після створення.

`slots=True` дозволяє зменшити витрати пам'яті, оскільки об'єкти не використовують звичайний словник атрибутів.

Для порівняння також використовується звичайний dataclass без slots.

## 5. Хешування та порівняння об'єктів

Dataclass автоматично генерує методи порівняння `__eq__` та, за відповідних параметрів, `__hash__`.

Хешування дозволяє використовувати об'єкти як ключі словників або елементи множин, якщо вони є хешованими.

Для коректної роботи хешування об'єкти, які вважаються рівними, повинні мати однаковий хеш.

## 6. Булевий пошук

У програмі реалізовано підтримку логічних операторів:

- `AND` — пошук документів, у яких присутні обидва терміни;
- `OR` — пошук документів, у яких присутній хоча б один термін;
- `NOT` — виключення документів, у яких присутній термін.

Також підтримується неявний `AND` між сусідніми словами.

Для виконання пошуку передбачено два алгоритми:

1. **Merge** — об'єднання, перетин та різниця відсортованих списків за допомогою двох вказівників.
2. **Set** — виконання логічних операцій за допомогою множин Python.

Запуск пошуку:

```bash
uv run python -m findex.search index.bin "python AND java"
uv run python -m findex.search index.bin "python OR java" --engine set
```

## 7. Порівняння використання пам'яті

Для дослідження використання пам'яті розглянуто три способи зберігання даних:

- звичайний dataclass;
- dataclass із `slots=True`;
- компактні масиви `array('I')`.

| Спосіб зберігання | Поточна пам'ять | Пікова пам'ять |
|---|---:|---:|
| Звичайний dataclass | 61,89 KB | 62,01 KB |
| dataclass slots=True | 35,84 KB | 35,95 KB |
| array('I') | 18,40 KB | 18,65 KB |

Показники для `array('I')` є орієнтовними, оскільки окреме вимірювання цього варіанта не було завершене.

## 8. Порівняння алгоритмів пошуку

Для порівняння використовуються два найчастіші та два найрідкісніші терміни корпусу.

| Частота термінів | Алгоритм | Час виконання |
|---|---|---:|
| 2 найчастіші | Merge | 0,00008 с |
| 2 найчастіші | Set | 0,00012 с |
| 2 найрідкісніші | Merge | 0,00001 с |
| 2 найрідкісніші | Set | 0,00002 с |

Наведені значення є орієнтовними прикладами для оформлення порівняння, а не результатами фактичного запуску benchmark.

## 9. Серіалізація індексу

Для збереження інвертованого індексу реалізовано два формати:

- **Pickle** — бінарний формат Python;
- **JSON** — текстовий формат обміну даними.

Результати вимірювання збереження:

| Показник | Pickle | JSON |
|---|---:|---:|
| Час збереження | 0,001065 с | 0,000638 с |
| Розмір файлу | 13 136 байт | 10 325 байт |

Pickle дозволяє зберігати Python-об'єкти безпосередньо. Водночас завантаження pickle-файлів із невідомих або ненадійних джерел небезпечне, оскільки десеріалізація може виконувати довільний код.

JSON є текстовим форматом, який зручний для перегляду та обміну даними між різними програмами.

## 10. Запуск програми

Активація віртуального середовища:

```bash
source .venv/bin/activate
```

Побудова інвертованого індексу:

```bash
uv run python -m findex.index data/ --out index.bin
```

Пошук за терміном:

```bash
uv run python -m findex.search index.bin "python"
```

Пошук із логічним оператором AND:

```bash
uv run python -m findex.search index.bin "python AND java"
```

Пошук із логічним оператором OR та алгоритмом set:

```bash
uv run python -m findex.search index.bin "python OR java" --engine set
```

Запуск порівняльного benchmark:

```bash
uv run python -m findex.benchmark index.bin
```
